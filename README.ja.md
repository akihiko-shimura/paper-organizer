# paper-organizer

[English](README.md) | 日本語

名前がばらばらな論文 PDF のフォルダを、検索でき、引用に使え、AI エージェントに渡せる蔵書に変えます。
ファイルを何かのソフトに取り込むことはしません。

`paper-organizer` は、各 PDF を Crossref と arXiv に照らして同定し、読める名前に改名し、重複を脇へよけ、
手元に検索の索引を作ります。Python のファイル 1 つでできていて、標準ライブラリ以外への依存はありません。
コマンドラインから `papers` として使います。

```
1-s2.0-S0030401899001234-main.pdf   →  1999_Smith_OptCommun_164_1_123.pdf
oe-27-8-11018.pdf                   →  2019_Smith_OptExpress_27_8_11018.pdf
2001.01234v2.pdf                    →  2020_Sato_arXiv_2001.01234.pdf
```

（命名規則 `year_FirstAuthor_Journal_volume_issue_page.pdf` を示すための架空の例です。）

**現状。** 作者が、約 3,200 件の PDF からなる 1 つの蔵書で使っています。今のところ macOS 専用です。
コマンドの出力は日本語です。

このページは、ツールを使いたい人のための短い版です。

- 日々の使い方: [MANUAL.ja.md](MANUAL.ja.md)
- 開発者向け（内部の仕組み、すべての測定、採らなかった案、未対処の問題）: [docs/design.ja.md](docs/design.ja.md)

## なぜ作ったか

何年もかけて増えた論文フォルダは、どこでも似た姿になります。`1-s2.0-S…-main.pdf`、`oe-27-8-11018.pdf`、
`document(3).pdf`。同じ論文が 3 つの名前で 3 回保存されている。テキスト層のないスキャンがある。論文を探すには、
どのフォルダに入れたかを思い出すか、Spotlight で著者名や誌名、出版年、キーワードを検索することになります。
「この論文はもう持っているか」に答えるには、その結果を目で確かめるしかありません。

欲しかったものは 2 つです。

- **人が読めるファイル名。** 手で打つのではなく、出版社自身の記録から作ります。
- **AI エージェントが問い合わせられる索引。** 参考文献リストを確かめるアシスタントが、「DOI X はディスクにあるか、
  どこにあるか」と尋ねて、推測ではなく正確な答えを得られるようにします。

文献管理ソフトは、ファイルを自分のライブラリに取り込んでこれを行います。このツールは、ファイルを
あなたが作ったフォルダの中に置いたままにします。

### Spotlight の検索では足りないのか

Spotlight が探すのは、ファイルの中の語です。そのファイルが何の論文かは知りません。そのため、その話題の論文も、
語に一度触れただけの論文も、同じ 1 件として返ります。作者の蔵書で測りました。

| 問い | Spotlight | paper-organizer |
|---|---|---|
| キーワードで探す（8 語句） | 1 語句あたり平均 669 件。語が表題にあるのは 7% | 順位つき。上位 10 件の 81% は語が表題にある |
| この DOI を持っているか（60 件） | 37 件を発見。残り 23 件は PDF に DOI の印刷なし | 60 件を発見 |
| この著者の論文（姓 15 個） | 返った中で本人の論文は 5%。残りは名前の引用 | `author:` で著者欄だけを検索 |
| スキャンの PDF を探す（37 件） | 1 件を発見 | OCR して索引に入れる |

語が本文の奥にしか出ない論文を探すなら、Spotlight のほうが向いています。Spotlight は全ページを読みます。
このツールの索引が持つのは、最初の 3,000 文字と抄録です。Spotlight が画面で並べる順は、測れませんでした。
方法と注意点は [docs/design.ja.md の 13 節](docs/design.ja.md#13-検索)にあります。

## ほかのツールとの違い

各プロジェクトの公開ドキュメント（2026 年 10 月時点）に基づきます。

| | 文献管理ソフト（[Zotero](https://www.zotero.org/support/retrieve_pdf_metadata)） | 改名ツール（[pdf2doi](https://github.com/MicheleCotrufo/pdf2doi)、[pdf-renamer](https://github.com/MicheleCotrufo/pdf-renamer)） | レイアウト抽出（[GROBID](https://grobid.readthedocs.io/en/latest/Introduction/)） | paper-organizer |
|---|---|---|---|---|
| ファイル | ライブラリに取り込む | 元の場所のまま | 元の場所のまま | 元の場所のまま |
| メタデータの出どころ | 自前の照会サービス | DOI か arXiv ID の照会 | モデルがページを読む | Crossref か arXiv の照会だけ |
| 記録がこの PDF のものかの確認 | — | 識別子の存在 | — | 記録と 1 ページ目のヘッダの一致 |
| 動作環境 | デスクトップアプリ | Python パッケージ | Java のサービスか Docker | Python のファイル 1 つ |
| 用途 | 執筆と引用 | 改名 | 大規模なテキストマイニング | 既存の山の整理。エージェントの「持っているか」 |

このツールに固有の点は次のとおりです。

- **照会の結果をすべて裏取りします。** PDF に印刷された DOI は、参考文献リストのものかもしれません。裏取りが
  無かったときは、214 件中 5 件または 6 件が、警告なしに別の論文の名前を付けられていました。
- **正直に「分からない」と言います。** 裏取りに通らないファイルは改名せず、人が見るための一覧に載せます。
- **エージェント向けのコマンド**: DOI や arXiv ID での厳密な照会、JSON 出力、BibTeX、そして
  [Claude Code の skill](skills/paper-search/SKILL.md) があります。

引用プラグインや注釈の同期が欲しい場合は、文献管理ソフトが向いています。Windows と Linux には、まだ対応して
いません。ファイルの大半が学位論文、書籍、英語以外の論文である場合も、このツールは向きません。

## 仕組み

**同定は照合であって、生成ではありません。** このツールが PDF から取るのはキーだけです。キーは、DOI、arXiv ID、
検索クエリのどれかです。書誌の値はすべて、そのキーが指す登録データベースから取ります。推定はしません。

```
PDF → 1〜2 ページ目の本文(テキスト層が無ければ OCR)
    → 裏取りに通るまで、次の順でキーを探す
        1. 余白にある arXiv の刻印          → arXiv
        2. PDF のメタデータの DOI           → Crossref
        3. 本文に印刷された DOI             → Crossref
        4. 本文かファイル名の arXiv ID      → arXiv
        5. 最初の 300 文字を検索クエリに    → Crossref (表題が本文に文字どおりあること)
        6. 推測した表題を検索クエリに       → Crossref (類似度 0.92 以上)
    → 裏取り: 第一著者の姓 かつ (年 または 誌名 または 巻 または 開始ページ) が、
              1 ページ目の最初の 1,500 文字にあること
    → 解決済み │ unverified │ unresolved    (改名するのは解決済みだけ)
```

同定のあとに、次のことをします。

- **抄録**を OpenAlex から取ります。
- **重複**（同じ DOI）を保留フォルダへ移します。最も大きいファイルを残します。
- **検索**には、表題・著者・誌名・抄録・本文の最初の 3,000 文字を対象にした、SQLite の全文索引を使います。
- **ビュー**は、誌名・年・分野・第一著者ごとのシンボリックリンクのフォルダです。Finder で使います。
- **ページの検証**（任意、`vet.py`）では、Claude Haiku が 1 ページ目の画像から表題を読みます。できるのは、記録を
  人に差し戻すことだけです。値を書き込むことはありません。

状態はすべて、1 つの JSON Lines ファイル `papers.jsonl` にあります。PDF 1 つにつき 1 記録です。

## どのくらい正確か

1 つの蔵書で測りました。約 3,200 件の PDF で、大半は光学と物性物理、大半は英語です。ほかの分野では結果が
変わります。

| | 結果 |
|---|---|
| 同定して改名できた | 3,175 件中 2,291 件（72%） |
| 人手行き | 843 件（27%） |
| 同定したものの誤り（無作為標本を目で確認） | 38 件中 0 件 |
| 裏取りを入れる前の誤り | 214 件中 5 件または 6 件（2.3〜2.8%） |

- 38 件中 0 件から分かるのは、誤り率がおおよそ 10% 未満だということだけです。
- 人手行きには、Crossref に無い学位論文・書籍・報告書・講義ノートと、自動の問い合わせが外れた論文が入っています。

すべての測定と標本の大きさは [docs/design.ja.md の 16 節](docs/design.ja.md#16-測定のまとめ)にあります。

## この設計にした理由

- **LLM やレイアウト解析ではなく、照会。** 登録データベースは、出版社自身の記録を返します。名前の綴りも含みます。
  項目を書くモデルは、もっともらしく間違えることがあります。
- **関連度スコアではなく、文字列の比較。** Crossref のスコアは、正しい結果と誤った結果で重なります。
- **既定は全文検索で、埋め込みではない。** 小さな試験（20 件に 8 クエリ）では、汎用の埋め込みのほうが、正しい論文の
  順位が低くなりました。埋め込み検索は、任意の機能として入れてあります。
- **ファイルは元の場所のまま。** フォルダへの振り分けも、削除もしません。

測ったうえで採らなかった 12 の案は
[docs/design.ja.md の 17 節](docs/design.ja.md#17-測ったうえで採らなかった案)にあります。

## 使い始める

**必要なもの**

- macOS
- Python 3.9 以降（インストールするパッケージはありません）
- [poppler](https://poppler.freedesktop.org/): `brew install poppler`
- 任意: Xcode のコマンドラインツール（`swiftc`）。OCR に使います
- 任意: [uv](https://docs.astral.sh/uv/) と Anthropic の API キー。ページの検証（`vet.py`）に使います

**インストール**

```bash
git clone https://github.com/<owner>/paper-organizer.git
cd paper-organizer
mkdir -p ~/.local/bin
ln -s "$PWD/organize.py" ~/.local/bin/papers     # ~/.local/bin が PATH に入っていること
papers selftest                                   # 通信なしの自己検査。「selftest: ok」と出る
```

**設定**（任意ですが、おすすめします）

```bash
cp config.example.json config.json
```

`mailto` に自分のメールアドレスを設定します。Crossref と OpenAlex は、連絡先の付いたリクエストを、より安定して
扱います。抄録のためには、無料の OpenAlex の API キーをおすすめします。`OPENALEX_API_KEY` を設定するか、macOS の
キーチェーンに `openalex-api-key` として保存します。

**最初の実行**

まず、小さなフォルダのコピーで試してください。

```bash
papers add ~/Papers          # フォルダの下の PDF を全部同定し、索引を作る
```

最初のスキャンは 1 ファイルあたり数秒かかるので、3,000 件の PDF で 2〜4 時間です。中断して再開できます。
この時点では、何も移動せず、何も改名しません。`add` は最後に、`dedup` と `rename` が行うはずのことを表示します。
内容に納得できたら、次を実行します。

```bash
papers dedup --apply         # 重複を脇へ移す(削除はしない)
papers rename --apply        # 解決済みのファイルを改名する
papers index && papers views # 検索の索引と Finder 用のビューを作り直す
```

あとで新しい PDF を足すときも `papers add` です。まだ索引にないファイルだけを見ます。

## 使い方

| コマンド | すること |
|---|---|
| `papers add [folder]` | 新しい PDF を索引に入れ、改名と重複の予定を表示 |
| `papers search "fiber laser"` | 検索。`AND`、`OR`、`NOT`、`"語句"`、`title:`、`author:`、`journal:` |
| `papers has 10.1234/abcd` | この DOI や arXiv ID を持っているか、どこにあるか |
| `papers cite 10.1234/abcd` | BibTeX |
| `papers info` | 索引の場所と件数 |
| `papers fix NAME --doi DOI` | 記録を 1 件直す |
| `papers review` → `papers merge` | 未解決のファイルの候補をまとめて確認 |
| `papers move NAME --to FOLDER` | ファイルを移し、索引も更新 |
| `papers relocate` | 手でファイルを動かしたあとの索引の修復 |
| `papers undo` | 直前の改名または移動の取り消し |

`search`、`has`、`info`、`recent` に `--json` を付けると、1 行 1 記録で出力します。詳しい手引きは
[MANUAL.ja.md](MANUAL.ja.md) です。

**Claude Code と使う**

```bash
mkdir -p ~/.claude/skills ~/.claude/agents
ln -s "$PWD/skills/paper-search" ~/.claude/skills/paper-search
ln -s "$PWD/agents/paper-librarian.md" ~/.claude/agents/paper-librarian.md
```

- **skill** は、「…の論文は持っているか」「手元の論文から…についての論文を探して」と尋ねると読み込まれます。
  エージェントはファイルのパスで答え、書誌の詳細を事実として述べるのは検証済みの記録に限ります。
- **司書サブエージェント** は、PDF の追加、論文の選択、移動の提案をします。あなたが特定の一覧を承認したと依頼文に
  書いていない限り、dry run で止まります。

## 安全性

- **PDF を削除することはありません。** 重複は保留フォルダへ移します。削除するかどうかは、あなたが決めます。
- **既定は dry run です。** `dedup`、`rename`、`move`、`relocate`、`fix` は、`--apply` を付けるまで何も変更しません。
- **バックアップと取り消し。** 索引は、書き換える前に `backups/` へコピーします。`papers undo` は、直前の改名または
  移動を元に戻します。
- **有料の呼び出しには同意が必要です。** `vet.py` は費用の見積もりを表示し、`--apply` がなければ何も送信しません。

## マシンの外に出るもの

| 送り先 | 送るもの | いつ |
|---|---|---|
| Crossref | DOI。検索クエリとして、本文の最初の 300 文字と推測した表題。設定していれば連絡先のメールアドレス | `add`, `scan`, `review`, `pubver`, `fix --doi` |
| arXiv | arXiv ID | `add`, `scan` |
| OpenAlex | DOI。設定していれば API キーと連絡先のメールアドレス | `add` |
| Anthropic | 1 ページ目の画像 | `vet.py --apply` のときだけ |

PDF ファイルそのものは、アップロードしません。**索引（`papers.jsonl`）を公開しないでください。** 各論文の最初の
3,000 文字と抄録が入っていて、これらは著作権のある文章です。

## 制限

- **macOS 専用です。** OCR とキーの保存に、Apple のフレームワークを使います。
- **1 人、1 台のマシン向けです。** 索引は絶対パスを保存します。
- **すべてを同定できるわけではありません。** 学位論文、書籍、多くの学会の要旨は Crossref にありません。日本語など、
  ラテン文字以外の表題は照合できません。
- **同じ表題の別の版**は、1 ページ目に誌名も巻もページも印刷されていなければ区別できません。
- **プレプリントとして認識するのは arXiv だけです。** プレプリントと出版版は、互いにリンクした 2 つの記録です。
- **重複は DOI だけで検出します。**
- **検索が見るのは最初の 3,000 文字です。** 本文の奥の語は、Spotlight で探してください。

全一覧は [docs/design.ja.md の 15 節](docs/design.ja.md#15-既知の未対処)にあります。

## 費用

同定、抄録、検索は、無料の公開 API を使います。有料の機能は、任意のページの検証（`vet.py`、Claude Haiku）だけです。
作者の蔵書では、3,203 件で 3.31 USD でした。
